# Nested Layouts

---

## Definition

Layouts can contain other layouts.

This allows complex interfaces to be built from simple layout blocks.

---

## Example

Vertical Layout

↓

Label

↓

Label

↓

Horizontal Layout

↓

Button

Button

---

## Benefits

- Responsive UI
- No manual positioning
- Easy maintenance
- Reusable design

---

## Key Takeaway

Large interfaces are created by nesting simple layouts together.
