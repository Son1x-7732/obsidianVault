# QLabel

---

## Definition

`QLabel` is a widget used to display read-only content.

It can display:

- Plain text
- Rich text (HTML)
- Images
- Animated GIFs
- Links

---

## Why does QLabel exist?

Many GUI elements need to display information but do not require user interaction.

Instead of using a generic widget, Qt provides `QLabel`.

---

## Inheritance

QObject

↓

QWidget

↓

QFrame

↓

QLabel

---

## Responsibilities

A QLabel can:

- Display text
- Display images
- Align content
- Change fonts
- Change colors
- Word wrap text

## Key Takeaways

- QLabel is for displaying information.
- It is not editable.
- It inherits all QWidget functionality.
