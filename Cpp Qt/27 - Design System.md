# Visual Hierarchy

---

## Definition

Visual hierarchy guides the user's attention by making important elements more prominent than less important ones.

---

## Ways to create hierarchy

- Font size
- Font weight
- Spacing
- Alignment
- Colors
- Button size

---

## Good hierarchy

Title

↓

Subtitle

↓

Primary Actions

---

## Principle

A user should know where to look within a few seconds.
