# Application Theme

---

## Definition

A theme contains the visual appearance of the application.

It defines fonts, colors, spacing and styling for every widget.

---

## Why?

Without a global theme every widget must be styled individually.

A theme provides consistency across the application.

---

## Theme should control

- Font family
- Font size
- Colors
- Button style
- Margins
- Icons

---

## Principle

Widgets should focus on behaviour.

The application theme should focus on appearance.
